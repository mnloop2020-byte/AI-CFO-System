# AI CFO System

AI-powered financial management platform for small and medium-sized businesses.

## Key Features

* Multi-agent architecture for Sales, Accounting, Cash Flow, Inventory, Tax, Fraud Detection, Reporting, and Executive Insights.
* CRM modules for customers, sales, expenses, invoices, and inventory.
* RAG-based document retrieval with pgvector.
* Conversation memory and AI-powered financial analysis.
* Financial reports and business recommendations.
* Role-aware API architecture with audit-ready design.

## Tech Stack

* Frontend: Next.js, TypeScript, Tailwind CSS
* Backend: Python, FastAPI
* Database: Supabase, PostgreSQL, pgvector
* AI: LLM APIs, AI Agents, RAG, SentenceTransformers

## Project Structure

* `frontend/` - Next.js web application
* `backend-python/` - FastAPI backend and AI agents
* `docs/` - Project documentation

## Status

The project is actively being developed and tested as a production-oriented AI finance platform.
